# JobSearch AI • Intelligent Career Hunter & Fit Scorer

An autonomous, AI-powered job aggregation and scoring platform built for **multi-candidate use** (tailored for you and your brother). It pairs an automated **n8n orchestration workflow** with a **React + Vite dark-mode dashboard** and persists scored postings in **Supabase**.

## 🗄️ Supabase Database Setup

If configuring a new Supabase project, execute this SQL in the **Supabase SQL Editor**:

```sql
create table if not exists public.jobs (
  id bigint generated by default as identity primary key,
  hash_id text unique not null,
  company text,
  title text,
  location text,
  job_url text,
  description text,
  match_score numeric,
  reasoning text,
  profile_id text default 'aridon',
  source text default 'Google Jobs',
  created_at timestamptz default now()
);

-- Index for rapid scoring queries and deduplication
create index if not exists idx_jobs_hash_id on public.jobs(hash_id);
create index if not exists idx_jobs_match_score on public.jobs(match_score desc);
create index if not exists idx_jobs_profile_id on public.jobs(profile_id);
```

## ⚡ n8n Workflows

In this repository, you have two workflow definitions:

1. **`Automated Job application.json`**:
   The original n8n Cloud backup.
2. **`Automated Job application (Multi-Profile Enhanced).json`** *(Recommended)*:
   Enhanced workflow with:
   - **Fixed Deduplication**: Resolved the node reference (`Check Existing Hashes` instead of `Supabase`), ensuring net-new jobs are correctly deduplicated before scraping.
   - **Multi-Profile AI Scoring**: The LLM prompt dynamically receives the active candidate's name, title, and skill set from the frontend webhook payload.
   - **Proper `reasoning` Serialization**: Serializes `summary`, `pros`, `cons`, and `missing_keywords` so Supabase and the email digest parser receive valid JSON.
   - **Dynamic Email Alerts**: Dispatches digest emails to the specific user's email passed in the webhook payload.
